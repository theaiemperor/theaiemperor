## You can generate own custom file using following steps


### For snake game
Go to repo settings > Actions tab > choose general option then

1. Action permissions > enable 'Allow all actions and reusable workflows' setting
2. Workflow permissions > enable 'read & write permissions'
3. Use my .github workflow's snake.yml to your workflows

And you are ready to implement snake game.
